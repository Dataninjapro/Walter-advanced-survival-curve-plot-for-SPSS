# מדריך שימוש — תרשימי הישרדות ב־SPSS באמצעות R

## הפעלה ראשונה

1. הורידו את [קובץ גרסה 7](../SPSS_KM_Clinic_v7_LineStyle.sps).
2. פתחו את קובץ הנתונים ב־SPSS והפכו אותו לקובץ הפעיל.
3. פתחו את קובץ ה־Syntax בעורך SPSS.
4. ערכו את אזור `USER SETTINGS` בראשו.
5. הריצו את הקובץ כולו, כולל שורות הפתיחה והסיום של בלוק R.

התרשים יופיע ב־Output Viewer והכיתוב יופיע גם כטקסט להעתקה. אין צורך ב־ggplot2 או ב־survminer. חבילת survival צריכה להיות מותקנת וניתנת לטעינה בסביבת R של SPSS; הקוד אינו מתקין חבילות.

## מיפוי המשתנים

```r
TIME_VAR <- "survtime"
STATUS_VAR <- "status"
GROUP_VAR <- "clinic"
ID_VAR <- "id"
EVENT_VALUE <- 1
CENSOR_VALUE <- 0
```

כל שורה מייצגת אדם אחד. הזמן מספרי, סופי ולא שלילי; יחידות הזמן בדוגמה הן ימים. משתנים אחרים בקובץ אינם נכללים במודל. קוד האירוע וקוד הצנזור חייבים להיות שונים. ערכים חסרים בזמן, באירוע או בקבוצה מוצאים מהניתוח. כפילות או חוסר במזהה בקרב המקרים השלמים עוצרים את ההרצה. אפשר לכבות את בדיקת המזהה באמצעות `ID_VAR <- NULL`.

## סדר הקבוצות ושמותיהן

ברירת המחדל היא סדר רמות שמתקבל מ־R לפי קודי הקבוצה. לקביעה מפורשת בדוגמה:

```r
GROUP_ORDER <- c("0", "1")
GROUP_LABELS <- c("Clinic 0", "Clinic 1")
```

יש לכלול את כל הקבוצות שנצפו, ללא כפילויות, ולספק שם אחד לכל קבוצה באותו סדר. השמות מופיעים במקרא, בטבלת הסיכון ובכיתוב. למשל, אפשר להחליף את השמות ל־Treatment Group A ו־Treatment Group B.

כאשר Cox מופעל, ה־HR מתייחס **לקבוצה השנייה ביחס לראשונה**. שינוי הסדר משנה את כיוון ההשוואה.

## אפשרויות הניתוח והטקסט

| הגדרה | תפקיד |
| --- | --- |
| `SHOW_LOGRANK` | הצגת ערך P של מבחן Log-rank כולל |
| `SHOW_SIGNIFICANCE_TEXT` | ניסוח מותנה של מסקנת Log-rank; המבחן מחושב גם אם ערך P מוסתר |
| `SIGNIFICANCE_ALPHA` | סף המובהקות, ברירת מחדל 0.05; מובהק כאשר P קטן מהסף |
| `SHOW_COX_HR` | HR ממודל Cox לא מתוקנן, בשתי קבוצות בלבד |
| `CONF_LEVEL` | רמת רווח הסמך, ברירת מחדל 0.95 |
| `SHOW_CI` | הצגת רצועות רווח סמך סביב העקומות |
| `SHOW_POLISHED_CAPTION` | יצירת פסקה משולבת מתוך התוצאות שהופעלו |
| `VERBOSE_OUTPUT` | הצגת טבלאות R ופרטי הבדיקה כאשר TRUE |

להצגת הפסקה המלאה:

```r
SHOW_POLISHED_CAPTION <- TRUE
SHOW_LOGRANK <- TRUE
SHOW_SIGNIFICANCE_TEXT <- TRUE
SHOW_COX_HR <- TRUE
VERBOSE_OUTPUT <- FALSE
```

הפסקה נוצרת מהמספרים שחושבו, ולא מפענוח הפלט המודפס. היא משלבת את שמות הקבוצות, מסקנת המובהקות, P ו־HR עם רווח סמך בהתאם לאפשרויות. אם Cox כבוי או שהאומדן בעייתי, HR אינו נכלל. שגיאות והודעות אבחון חשובות אינן מוסתרות עם הטבלאות.

דוגמת ניסוח בלבד — המספרים אינם תוצאה של קובץ נתונים בריפו:

> Kaplan-Meier survival curves comparing Treatment Group A and Treatment Group B. The difference in survival was statistically significant (Log-rank test: P = 0.003; Unadjusted Cox proportional hazards model: HR = 1.60, 95% CI [1.20-2.10] (Treatment Group B vs Treatment Group A)).

אין להסיק מהיעדר מובהקות שהקבוצות שקולות. המובהקות במשפט מתייחסת ל־Log-rank, ולא למבחן המקדם ב־Cox. במודל Cox אין כרגע התאמה לקו־וריאנטים.

הקוד בודק את הנחת הסיכונים הפרופורציונליים עם `cox.zph`. הודעה תוצג אם הבדיקה הגלובלית נותנת P קטן מ־0.05; סף אבחון זה נפרד מ־`SIGNIFICANCE_ALPHA`. הודעת אבחון אינה מסירה אוטומטית HR סופי, ויש לבחון את פירושו.

## עיצוב, גודל ורזולוציה

| הגדרה | תפקיד |
| --- | --- |
| `TITLE` | כותרת התרשים |
| `X_LABEL`, `Y_LABEL` | שמות הצירים |
| `TIME_MAX` | גבול הזמן המוצג; NULL משתמש במעקב המרבי |
| `TIME_BREAKS` | נקודות הזמן בציר ובטבלת הסיכון; NULL לבחירה אוטומטית |
| `WIDTH`, `HEIGHT` | רוחב וגובה באינצ׳ים |
| `PNG_DPI` | מספר פיקסלים לאינץ׳ |
| `FONT_PT` | גודל פונט בסיס בנקודות |
| `CENSOR_SIZE` | גודל סימן הצנזור |
| `CENSOR_LWD` | עובי סימן הצנזור |
| `CURVE_LWD` | עובי העקומות; LWD הוא Line Width |
| `ALL_LINES_SOLID` | TRUE לכל הקווים רציפים; FALSE לסוג קו שונה לכל קבוצה |

לכל קבוצה צבע שונה בכל אחד ממצבי הקווים, והמקרא מותאם לבחירה. סימון הצנזור הוא +; סימון אחד בנקודת זמן יכול לייצג יותר ממקרה מצונזר אחד באותו זמן.

קובץ v7 המקומי שהועלה כולל גודל 3×3 אינץ׳, פונט 6, ורזולוציה 300 DPI — כלומר **900×900 פיקסלים**. ההערה ליד DPI בקובץ המקורי מתייחסת להגדרה ישנה; חישוב הממדים נקבע מהערכים עצמם.

פרופיל גדול יותר שנבדק במהלך הפיתוח:

```r
WIDTH <- 4
HEIGHT <- 4
PNG_DPI <- 300
FONT_PT <- 8
CENSOR_SIZE <- 0.8
CENSOR_LWD <- 1.0
CURVE_LWD <- 1.0
```

כך מתקבלת תמונה בגודל 1200×1200 פיקסלים. התאימו גודל ופונט יחד; כיתובים ארוכים או קבוצות רבות עשויים לדרוש שטח נוסף. הגדלה ידנית של תמונה אינה מוסיפה פרטים. ה־Viewer עשוי להתאים את גודל התצוגה לחלון גם כשהמקור ברזולוציה גבוהה.

`TIME_MAX` ו־`TIME_BREAKS` משפיעים על התצוגה בלבד. הם אינם מגבילים את הנתונים המשמשים לחישוב KM, Log-rank או Cox.

## מגבלות שיש להכיר

- הקוד מכבד FILTER פעיל בקריאת הנתונים, אך אינו משנה את הגדרות SPSS.
- WEIGHT אינו מיושם; הניתוח אינו משוקלל.
- SPLIT FILE אינו מפצל את הניתוח; המקרים הנקראים מנותחים יחד.
- הפריסה תומכת ב־2 עד 6 קבוצות. עבור יותר משתי קבוצות חובה להגדיר `SHOW_COX_HR <- FALSE`.
- במצב של יותר משתי קבוצות, Log-rank הוא מבחן כולל ולא השוואות זוגיות.
- טבלת הסיכון סופרת אנשים עם זמן מעקב גדול או שווה לנקודת הזמן, מיד לפני האירועים באותה נקודה.
- הניתוח מיועד לצנזור ימני רגיל ולכניסה בזמן אפס. אין תמיכה בכניסה מאוחרת, סיכונים מתחרים או אירועים חוזרים.
- אין בריפו נתוני משתתפים או תרשימים מהנתונים האמיתיים.

## פתרון בעיות

- **R לא עולה:** בדקו את שילוב R של התקנת SPSS. זהו Syntax שמיועד להרצה מתוך SPSS, ולא קובץ R עצמאי.
- **survival חסרה:** בדקו את הספריות בסביבת R שאליה SPSS מחובר; התקנת R חיצונית אינה מבטיחה זמינות בתוך SPSS.
- **שם משתנה לא נמצא:** התאימו את השם המדויק, כולל רישיות.
- **קודי אירוע לא צפויים:** בדקו את `EVENT_VALUE` ו־`CENSOR_VALUE` ואת הנתונים בפועל.
- **HR חסר:** בדקו שיש שתי קבוצות וש־Cox מופעל. קראו הודעות על התכנסות או רווח סמך לא סופי.
- **התרשים צפוף:** הגדילו WIDTH/HEIGHT או קצרו את שמות הקבוצות והכותרת; התאימו גם FONT_PT.
- **נדרשת בדיקת מספרים:** הפעילו `VERBOSE_OUTPUT <- TRUE` להצגת ספירות, טבלת סיכון ותוצאות מפורטות.

היעד הוא SPSS 31/32. במהלך הפיתוח דווחה סביבת SPSS עם חבילת spssstatistics בגרסה 32.0.1.0, R בגרסה 4.6.1 ו־survival בגרסה 3.8-6. המשתמש אישר הצגת תרשימים מנתוניו; לא בוצעה בדיקת תאימות מלאה לכל גרסה או מערכת הפעלה.
